Its closure is recorded at the Phase 3 security review.
Output: one gated helper in `internal/auth`, one new configuration flag defaulting to off, and the first test file that package has had.
</objective>

    In `internal/config/config.go`, add `AuthLogOTP bool` to `Config` with a doc comment naming DR-2-01. Read it in `Load()` with the file's optional-env pattern: default `false`, set to `true` only when `os.Getenv("AUTH_LOG_OTP")` parses as a true boolean (accept `1` and `true`; anything else, including an unparseable value, warns and stays `false`).     Replace both `log.Printf("STAGING: OTP sent to user, code: %s", otp)` call sites with a single call to a new helper `func (h *Handler) logOTPIssued(otp string)`:
    - When `h.logOTPCode` is false — the default, and what staging runs — print `log.Printf("[AUTH] one-time sign-in code issued (code suppressed; set AUTH_LOG_OTP=1 to print)")`. The audit fact that a code was issued survives; the code does not. Do not include the email address, the user id, the code, its length, or any prefix of it.
    - When `h.logOTPCode` is true, print the existing line unchanged so a local developer gets exactly what they get today.
    Put a comment above the helper naming DR-2-01, the Phase 2 security review that deferred it, and the rule that no caller may print the code directly ever again.

    Then run `grep -rn "otp\|OTP" --include=*.go . | grep -i "log\.\|Printf\|Println"` across the repository and confirm the helper is now the only place a code can reach a log. Quote the command and its output in `03-07-SUMMARY.md`: that output is what answers the todo's "confirm production has no equivalent", since this binary is what production runs.

    Create `internal/auth/handler_test.go` in `package auth` — the first test file this package has had. Capture log output with `log.SetOutput(&buf)` and restore it with `defer log.SetOutput(os.Stderr)`. Write `func TestOTPNotLogged(t *testing.T)` with subtests:
    - `logs_issuance_without_the_code`: a handler with `logOTPCode` false; call `logOTPIssued("482913")`; assert the buffer is non-empty, contains `one-time sign-in code issued`, and does **not** contain `482913` anywhere.
    - `logs_the_code_only_when_flag_is_on`: `logOTPCode` true; the same call; assert the buffer contains `482913`.
    - `suppressed_line_carries_no_identifiers`: `logOTPCode` false; assert the buffer contains no `@` character and no digit sequence of four or more characters, so neither an email address nor a code fragment can be reintroduced without failing this test.
    Construct the `Handler` directly as a struct literal with just the `logOTPCode` field set — the helper needs no store, no Redis and no email sender, so the test needs no infrastructure and no skip.
