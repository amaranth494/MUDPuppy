<objective>
Record the game. From the moment a saved connection profile connects until it disconnects, everything sent to the game and everything the game sends back is stored as a session transcript, with each sent line marked human-typed or AI-issued, and with markers where autopilot took and gave back the wheel. The owner can list a profile's sessions by date and time over HTTP and read any one of them back.

Purpose: D-14 is the owner's own requirement, in his words: "logging is automatic based on the connection, not based on when auto is on or off... capturing all of the session itself from connection to disconnection." It is also half of REQ-reasoning-visibility's "stored in the session log" — the other half, decisions and reasoning, is stored separately by plan 03-08 so that reasoning never enters the transcript (D-12, D-14). D-15's stint markers are what Phase 6's debriefs will use to find a stretch at the wheel.
Output: migration `011` creating all three of this phase's tables in one up/down pair, a transcript store, the tap on the two MUD choke points, and two owner-scoped read endpoints.
</objective>

Evidence rule for this phase (owner-directed, binding): every criterion is proven by a canned report or an end-user screenshot; a database query is never evidence. That is why this plan's proof of "the transcript exists" is the HTTP read endpoint's response inside `evidence/03-canned-report.txt`, never a `SELECT`.

One migration, `011`, creates all three of this phase's tables together — `game_sessions`, `game_session_lines` and `ai_decisions` — even though `ai_decisions` is not written until plan 03-08. This is the orchestrator's decision (one up/down pair) and it is why this plan owns the migration file while plan 03-08 owns only the store that queries `ai_decisions`.

Go contract produced by this plan and consumed by plans 03-08 and 03-11:

- `type TranscriptSink interface { OpenGameSession(userID, connectionID uuid.UUID) (uuid.UUID, error); AppendGameLines(gameSessionID uuid.UUID, lines []GameSessionLine) error; CloseGameSession(gameSessionID uuid.UUID) error }` declared in `internal/session`, implemented by `*store.TranscriptStore`, wired in `cmd/server/main.go` via `sessionManager.SetTranscriptSink(transcriptStore)`. The interface lives in the consuming package so `internal/session` does not grow an import of `internal/store`.
- `func (m *Manager) SendCommandAs(userID, command, source string) error` — `source` is `"human"` or `"ai"`. The existing `func (m *Manager) SendCommand(userID, command string) error` stays, with its existing signature, delegating with `"human"`. Keeping the old signature means `internal/session/websocket.go:653` — the browser's only send path, covering typed input, aliases, triggers and timers alike — needs no change, and plan 03-08's driver is the only caller that passes `"ai"`.
- Line source vocabulary, fixed here and reused by plan 03-11's log page: `human`, `ai`, `game`, `marker`. No other value is permitted.
