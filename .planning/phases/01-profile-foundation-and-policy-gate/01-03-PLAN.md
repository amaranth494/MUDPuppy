Database queries are not accepted as proof for any criterion.
Output: five handlers in `internal/profiles/handler.go` with four fixed log format strings, four route blocks in `cmd/server/main.go`, and `internal/profiles/handler_test.go` — the third Wave 0 test file in 01-VALIDATION.md.
