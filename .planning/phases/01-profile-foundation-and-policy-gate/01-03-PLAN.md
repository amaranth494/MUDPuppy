<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → `/api/v1/profiles/{connection_id}/*` | Untrusted JSON body and untrusted `connection_id` path segment cross here |
| Session cookie → user identity | `sessionMiddleware` establishes `user_id` in the request context; every handler must scope to it |
| Handler → store | Only `ProfileUpdate` fields and the dedicated `AcceptPolicy` call may reach the row |

## STRIDE Threat Register

| Threat ID | Category | Severity | Component | Disposition | Mitigating Task |
|-----------|----------|----------|-----------|-------------|-----------------|
| T-1-01 | Tampering | High | `PutAISettings` body → acceptance columns | mitigate | 01-03-01 (`AISettingsResponse` carries no acceptance field; update built from three fields only) + 01-03-03 (`TestAISettingsCannotSetAcceptance`) |
| T-1-02 | Spoofing | Medium | `AcceptPolicy` recorded version | mitigate | 01-03-02 (version taken only from `policy.Version()`, request body never decoded) + 01-03-03 (`TestPolicyAcceptUsesServerVersion`) |
| T-1-03 | Elevation of Privilege / Information Disclosure | High | IDOR via `{connection_id}` | mitigate | 01-03-01 and 01-03-02 — every handler resolves through `getProfileByConnectionID`, whose `GetProfileByConnection` filters `WHERE connection_id = $1 AND user_id = $2`; no ad hoc query is introduced |
| T-1-04 | Denial of Service / Tampering | Medium | unbounded `conduct_rules` / `approach_guidance` / `model_name` | mitigate | 01-03-01 (`validateAISettings` 20000/20000/200 limits, cap and threshold at least 1) + 01-03-03 (`TestAISettingsRejectsOverLengthText`) |
| T-1-05 | Tampering | High | engage-gate decision | mitigate | 01-03-02 — gate reads only the server-fetched row through `store.EngageGateAllowed`; no client-supplied accepted flag exists in any request shape |
| T-1-08 | Elevation of Privilege | Medium | wrong HTTP verb reaching a write handler | mitigate | 01-03-02 and 01-03-03 — acceptance is POST-only at both the handler guard and the route switch; the ai-settings route rejects everything but GET and PUT |
| T-1-SC | Tampering (supply chain) | Low | `go.mod` | accept | No packages installed; tests use stdlib plus already-present `github.com/google/uuid` |
</threat_model>
