## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Approved document → running binary | The text the owner accepts must be the approved text; embedding removes the filesystem as a tampering surface at runtime |
| Client → recorded acceptance version | The version written on acceptance must originate here, never from a request |

## STRIDE Threat Register

| Threat ID | Category | Severity | Component | Disposition | Mitigating Task |
|-----------|----------|----------|-----------|-------------|-----------------|
| T-1-02 | Spoofing | Medium | `policy.Version()` | mitigate | 01-02-01 — version is parsed at init from the embedded document; plan 01-03's accept handler uses only this value, never a request field |
| T-1-07 | Tampering | Low | policy text delivery | mitigate | 01-02-01 — `go:embed` makes the text compile-time content; a missing or renamed file is a build failure, not a runtime 404, and 01-02-02 asserts the embedded text's identity |
| T-1-SC | Tampering (supply chain) | Low | `go.mod` | accept | `embed`, `strings` and `testing` are stdlib; no package is installed and `go.mod` must be unchanged |
</threat_model>
