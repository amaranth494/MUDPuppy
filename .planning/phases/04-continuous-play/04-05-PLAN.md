<objective>
Give the AI a reaction window instead of a scroll-back. Today's window is a pure byte ring: eight kilobytes of whatever arrived most recently, however long ago that was. With one decision per engage that was harmless; with a loop running for an hour it means every decision is read against text that may be minutes old, and the memory model's first rule — Immediate Context is roughly the last ten seconds of activity, and it is ephemeral — is not implemented at all.

Purpose: D-09 and the first layer of `.specify/specs/ai-memory-model-v1.md`, which governs memory in this project. The layer's two hard requirements are that it is bounded by age and that it never goes empty, because an engage after a quiet spell must still see the room the character is standing in. The exact seconds and the retained-screenful size are Claude's discretion; the two rules are not.
Output: a ring buffer with a time dimension, a never-empty floor, an injectable clock, and the tests that pin all three.

Session Memory and Quest Memory are not in this plan — they are 04-07 and 04-08. This plan changes only what "recent" means.
</objective>
