<objective>
Make the mechanical limits mean something now that play is unbounded. A loop that never stops is exactly the thing the call cap, the error threshold and the disengage rules exist to bound, and until this plan they are numbers that nothing reads. This plan puts a counter in front of every model call, splits "the network hiccuped" from "the key is wrong" so a threshold can exist at all, adds the single 503 retry the owner asked for, stops a hostile room from spending a whole session on blocked commands, and makes every one of those halts visible in the panel, in the terminal and on the badge in the same message.

Purpose: REQ-call-cap-and-error-disengage in full, the three of REQ-safety-limits-hold's limits that are not about the connection, and four carry-forward remediations — D-14 (DR-3.1-02, the reviewer and retry calls count against the cap), D-16 (DR-3-04, one retry on a 503 with a notice while it retries), D-17 (consecutive blocks), D-18 (DR-3-03, the badge updates from the message that carries the disengage).
Output: the counters and the taxonomy split in the driver, the switch state and counts on the `ai` message, and the panel, terminal and badge changes that show them.

Every string this plan renders is locked verbatim in `04-UI-SPEC.md`'s Copywriting Contract. None of them interpolates vendor text.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| The loop → the owner's model quota and wallet | Every iteration can spend up to four model calls |
| Hostile game text → the block counter | An attacker who can cause blocks can try to exhaust the session |
| The driver's own state → the browser's badge | If they disagree, the owner believes the AI is stopped when it is not |
| Vendor error responses → the failure taxonomy | A misclassified error either stops play too early or never stops it |

## STRIDE Threat Register

| Threat ID | Category | Severity | Component | Disposition | Mitigation |
|-----------|----------|----------|-----------|-------------|------------|
