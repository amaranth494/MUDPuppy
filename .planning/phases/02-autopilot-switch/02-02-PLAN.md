<objective>
Put the switch behind an HTTP endpoint that answers only for the caller's own session and refuses to engage until Phase 1's gate says yes. `#AUTO ON` cannot engage a profile whose owner has not accepted the Safety and Abuse policy, cannot engage without a connected game, and cannot be aimed at somebody else's connection. The same endpoint answers `#AUTO STATUS`, and the existing 15-second status poll starts carrying the autopilot state so a page refresh re-syncs the badge from the server rather than from memory.

Purpose: this is the server half of ROADMAP criterion 1 and the whole of criterion 4's gate clause. Phase 1 built `EngageGateAllowed` and the refusal sentence and named them the Phase 2 contract; this plan calls them, it does not re-derive them. It is also where the canned report in plan 02-05 gets everything it can reach without a live MUD.
Output: an extended `internal/session/handler.go`, the package's first handler test file, and two small wiring edits in `cmd/server/main.go`.
</objective>

HTTP contract produced by this plan and consumed by plans 02-04, 02-05 and 02-06 (fixed here; the executor does not get to choose a different shape):

- `POST /api/v1/session/autopilot`, inside the same `sessionMiddleware`-wrapped mux every other session route uses.
- Request body `AutopilotRequest{ Action string ``json:"action"``; ConnectionID uuid.UUID ``json:"connection_id"`` }`. `Action` is one of `on`, `off`, `status`; anything else is a 400.
- Response body `AutopilotResponse` with `State string ``json:"state"`` ` (`on`, `waiting` or `off`, the state after the call), `Outcome string ``json:"outcome"`` `, `GateAllowed bool ``json:"gate_allowed"`` `, `GateMessage string ``json:"gate_message,omitempty"`` `, `PolicyVersion string ``json:"policy_version,omitempty"`` `.
- `Outcome` is exactly one of `engaged`, `disengaged`, `already-on`, `already-off`, `refused-gate`, `refused-no-session`, `status`. The browser maps outcome to the owner-visible wording; the server never composes a user-facing sentence except `GateMessage`, which is Phase 1's `store.EngageGateRefusalMessage` verbatim.
- `GET /api/v1/session/status` gains `AutopilotState string ``json:"autopilot_state"`` ` — no `omitempty`, so `off` is always transmitted and the browser can trust the field's presence.

Why the browser owns the wording: 02-UI-SPEC.md's Copywriting Contract is the single place the owner-visible strings live, and every one of them except the gate refusal is a frontend constant. The gate refusal sentence is Phase 1's locked contract (`internal/store/profile.go`) and travels from the server so it can never drift.

Phase 1 assets reused verbatim, never re-derived (RESEARCH "Don't Hand-Roll"): `store.EngageGateAllowed(policyVersionAccepted, policyAcceptedAt) bool` and `const store.EngageGateRefusalMessage`.
