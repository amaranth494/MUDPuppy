## Decisions Made

- The step-5 restore PUT reuses fixture `01-ai-settings-get-empty.json` in the `FIXTURE_FILES` array rather than adding a seventh fixture file, since the restored value (what step 1 found) and fixture 01's body are the same thing by construction. This keeps exactly six fixture files per directory, matching the plan's `files_modified` list precisely.
- Added `_get_never_issue_list`, a sibling to (not a modification of) `_get_field`, because the Never-issue list is the one field in this phase's responses that legitimately contains an embedded newline and, in the blocked decision's `notice`, an escaped quote — `_get_field`'s non-jq fallback is documented as single-line-safe and the plan's instruction was to reuse it unchanged, so a new helper was added instead of touching it.
- PUT bodies always echo back the exact `conduct_rules`, `approach_guidance` and `ai_settings` object captured from the preceding GET, changing only the field under test, matching the plan's explicit call-out that `PutAISettings` decodes the whole struct and would blank any field a naive partial body omitted.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Non-jq notice extraction truncated at the notice's own escaped quote**

- **Found during:** Task 2, self-test verification
- **Issue:** The first draft's non-jq fallback for extracting `failure_kind`/`notice` from the decisions response used a plain `"[^"]*"` grep pattern, which stops at the first `"` character — including the escaped `\"` inside the locked notice text `Matched Never-issue entry: \"give\"`. The extracted notice was silently truncated to `Matched Never-issue entry: \` in the printed report, though the non-empty check still passed.
- **Fix:** Changed the notice extraction pattern to `"notice"[[:space:]]*:[[:space:]]*"([^"\\]|\\.)*"` (matching the pattern already used for `never_issue_list`), then decoded `\"` and `\\` back to real characters after extraction.
- **Files modified:** `scripts/verify-phase3-1.sh`
- **Verification:** Re-ran `--self-test`; the report now shows the full notice text `notice: Matched Never-issue entry: "give"`.
- **Committed in:** `588d201` (part of the task 2 commit; caught before the commit was made)
