<objective>
Measure the enemy before building the defences. This plan writes the hostile-text corpus — room descriptions, other players' speech, item and sign text, text impersonating the game's system messages, text impersonating the owner or the conduct rules, staged multi-step setups, and benign controls — and a runner that pushes each window through the real `HandleEngage` with the real Gemini model behind it, then runs it once against the build as it stands today and files the BEFORE red-team report.

Purpose: D-10 makes the baseline the first thing this phase produces, so the phase can say what changed rather than only what was built. The runner written here is the same file that reruns unmodified in plan 03.1-07 for the AFTER report — that is why the fixture profile is a JSON file (`encoding/json` ignores the `never_issue_list` key today and populates it automatically once plan 03.1-02 adds the field) and why the report path and the strict pass bar are environment inputs rather than edits.
Output: a gated Go test with its corpus and fixture, and `evidence/01-redteam-before.txt`.

No sign-off stop follows this plan (D-10): the build plans start immediately.
